# 🌐 Kairos Web Landing Page

The clean, reason-driven landing page for **Kairos** — the zero-context-switch terminal collaboration mesh.

## Design Philosophy

- **Aesthetic:** Minimalist monochrome inspired by [Ossium](https://ossium.in/) and [Animos](https://animos.app/).
- **Visuals:** Architectural hairline grid, technical corner marks, segmented vertical progress indicator, and crisp typography.
- **Copy:** "The Reason Behind Everything" — concrete technical rationale for cognitive load, memory efficiency, latency, and workspace file streaming.
- **Interactive Sandbox:** Live in-browser terminal emulator supporting `/profile`, `/rooms`, `/share`, `/help`, and `/clear`.
- **Zero Emojis:** Strictly geometric SVG / Lucide icons throughout.
- **Modes:** Full support for both dark and light modes with system preference detection and `localStorage` persistence.

## Running Locally

```bash
cd client
bun run dev
```

Build for production:
```bash
bun run build
```
